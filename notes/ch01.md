## Section 1.1 Writing a Simple C++ Program.

Every C++ program has one or more functions, and one function **must** be named `main`.  

The operating system starts program execution by calling `main`.

```cpp
int main()
{
    return 0;
}
```

A function definition has 4 parts:

1. **Return type** (`int`)
2. **Function name** (`main`)
3. **Parameter list** (`()`)
4. **Function body** (`{ ... }`)

- `main` is special, but its definition syntax is the same as other functions.
- `()` means the function takes no parameters in this example.
- `main` must return `int`. `int` is a **built-in** C++ type used for integers.
- `return 0;` usually indicates successful execution to the operating system.
- The function body is a **block of statements** enclosed in `{}`.

```cpp
{
    return 0;
}
```

- In this example, the body contains one statement: `return 0;`.
- `return` ends function execution. A `return` statement may also send a value back to the caller.
- The **returned value must be compatible with the function’s return type.** 
- Here, `main` returns `int`, and `0` is an `int`, so it is valid.

> **Important NOTE:** Note the semicolon at the end of the return statement. 
> - Semicolons mark the end of most statements in C++. 
> - They are easy to overlook but, when forgotten, can lead to mysterious compiler error messages.

> **NOTE:** The value returned by `main` is the program’s **exit status**.
> - `0` means success.
> - Nonzero means an error (the exact meaning is system/program defined).
> On Linux, you can check the last exit status with:
> - `echo $?`

### Standard Output Streams

The standard library defines three `ostream` objects:
- **`cout`** (standard output) : Used for regular program output
- **`cerr`** (standard error) : Used for warning and error messages
- **`clog`** (general logging) : Used for general information about program execution

**endl**: This is a special value called a **manipulator**, which ends the current line and flushes the contents of the buffer associated with the device.

On UNIX : Press `Ctrl+D` to input an end-of-file character from the keyboard. -> To Finish the input and Execute


**Output** : 
```cpp

The sum of 3 and 7 is 10
```

> - Programmers often add print statements during debugging. Such statements should always flush the stream.

## 1.3 Comments

They are typically used to 
- Summarize an algorithm,
- Identify the purpose of a variable, 
- Clarify an otherwise obscure segment of code. 
The compiler ignores comments, so they have no effect on the program's behavior or performance.


Programmers tend to believe comments even when other parts of the system documentation are out of date. 
- An incorrect comment is worse than no comment at all because it may mislead the reader. 
- When you change your code, be sure to update the comments, too!

**Kinds of Comments in C++**

- Single-line comment: `//`
- Multi-line comment: `/* --- */`. The compiler treats everything between `/*` and `*/` as a comment. Note that they cannot be nested.

```cpp
#define SALESITEM_H
/*
 * Multi-line comment format
 * Add an asterisk to each line
 */
```

```cpp
#include <iostream>
/*
*
* Simple main function:
* Read two numbers and write their sum
*/
int main()
{
  // prompt user to enter two numbers
  std::cout << "Enter two numbers" << std::endl;
  float v1 = 0, v2 = 0;  // variables to hold the input we read
  std::cin >> v1 >> v2; // read input

  std::cout << "The sum of the " << v1 << " and " << v2 << " is " << v1 + v2
            << std::endl;

  return 0;
}
```

We often need to comment out a block of code during debugging. 
Because that code might contain nested comment pairs, the best way to comment a block of code is to insert single-line comments at the beginning of each line in the section we want to ignore:

```cpp
// /*
// * everything inside a single-line comment is ignored
// * including nested comment pairs
// */
```

## 1.4 Flow of Control
Statements normally execute sequentially: The first statement in a block is executed first, followed by the second, and so on. 

Of course, few programs—including the one to solve our bookstore problem—can be written using only sequential execution.

- With it, you write the logic once and let the computer repeat it as needed.

### 1.4.1 while Statement

- Executes a loop until the condition becomes false.

- A while statement repeatedly executes a section of code so long as a given condition is true.

> We can use a while to write a program to sum the numbers from 1 through 10 inclusive as follows:

```cpp
#include <iostream>
int main()
{

  int sum = 0, val = 1;
  // keep executing the whi leas long as val is less than or equal to 10
  while (val <= 10) {
    sum += val;    //  assigns sum + val to sum
    ++val;         // add 1 to val 
  }

  std::cout << "Sum of the numbers from 1 through 10 inclusive " << sum
            << std::endl;

  return 0;
}
```

**Output** 
```bash
Sum of 1 to 10 inclusive is 55
```

```text
while (condition)
    condition
```

A **condition** is an expression that yields a result that is either true or false. 
- So long as condition is true, statement is executed.
- After executing statement, condition is tested again. 
- If condition is again true, then statement is again executed.`

Uses the prefix increment operator (the ++ operator). Writing ++val is the same as writing val = val + 1

```cpp
++val;         // add 1 to val 
```

### 1.4.2 for Statement

Repeat a fixed number of times. The loop header consists of three parts:

- An initialization statement (init-statement)
- A loop condition (condition)
- An expression (expression)

> for loop to sum the numbers from 1 through 10 as follows:

```cpp
#include <iostream>
int main()
{
  int sum = 0;
  // sum values from 1 through 10 inclusive
  for (int val = 1; val <= 10; ++val)
  {
    sum += val; // equivalent to sum = sum + val
  }
  // Output the result
  std::cout << "Sum of the 1 to 10 inclusive is " << sum << std::endl;

  return 0;
}
```

To recap, the overall execution flow of this for is:

1. Create val and initialize it to 1.

2. Test whether val is less than or equal to 10. 
    - If the test succeeds, execute the for body. 
    - If the test fails, exit the loop and continue execution with the first statement following the for body.

3. Increment val.

4. Repeat the test in step 2, continuing with the remaining steps as long as the condition is true.


### 1.4.3 Reading an Unknown Number of Inputs

This means your program does not know beforehand how many values will be entered.

So instead of looping a fixed number of times, it keeps reading until input ends or fails.

```cpp
#include <iostream>
int main()
{
  int sum = 0, value = 0;
  // read until end-of-file, calculating a running total of all values read
  while (std::cin >> value) 
  {
    sum += value; // equivalent to sum= sum + value
  }
  std::cout << "Sum is : " << sum << std::endl;
  return 0;
}
```

If we give this program the input
```cpp
3 4 5 6
```

then our output will be

```cpp
Sum is:
18
```

### 1.4.4 The if Statement


```cpp
#include <iostream>

int main()
{
  // currVal is the number we're counting; we'll read new values into val
  int currVal = 0, val = 0;

  // read first number and ensure that we have data to process
  if (std::cin >> currVal){
    int cnt = 1; // store the count for the current value we're processing
    while (std::cin >> val)
    { // read the remaining numbers
      if (val == currVal) {        // if the values are the same
        ++cnt; // add 1 to cnt
      }
      else { // otherwise, print the count for the previous value
        std::cout << currVal << " occurs "
                  << cnt << " times" << std::endl;
        currVal = val; // remember the new value
        cnt = 1;       // reset the counter
      }
    } // while loop ends here
    // remember to print the count for the last value in the file
    std::cout << currVal << " occurs "
              << cnt << " times" << std::endl;
  } // outermost if statement ends here
  return 0;
}
```
Count how many times a number appears consecutively.

Example input:

```cpp
42 42 42 42 42 55 55 62 100 100 100 
```

**Output :**

```cpp
42 occurs 5 times
55 occurs 2 times
62 occurs 2 times
100 occurs 2 times
```

> - It is a common mistake to write `=` when you mean `==` inside a condition.
